# GrokMark

GrokMark is a small browser-local editor for adding clear AI labels to photos, illustrations, and drawings inside photos. The image stays on the device while the user edits it. Export uses the browser canvas, so the original file is never changed.

## The first slice

- Drop or select a PNG, JPG, or WEBP image.
- Try the built-in sample illustration without selecting a file.
- Change the label, position, opacity, size, ink color, and frosted backing.
- Download a marked PNG or JPG.

## Framework choice

This project uses Next.js with the App Router and TypeScript. That is the best fit for this version because the editor is a single client-heavy route, and Vercel supports Next.js with no custom server setup. The current implementation does not need a database, authentication, image storage, or API keys.

If the product grows, the next useful additions would be:

- A small server route for shareable projects or batch jobs.
- Object storage only if users need saved work across devices.
- A provider-neutral label system for Grok, ChatGPT, Midjourney, Stable Diffusion, and custom text.

Vite + React is a good alternative if the app stays fully static. SvelteKit is worth considering if the team prefers Svelte. For this project, Next.js keeps the Vercel path and future server features in one place.

## Run locally

    npm install
    npm run dev

Open http://localhost:3000.

## Deploy to Vercel

1. Push this project to GitHub, GitLab, or Bitbucket.
2. Import the repository in Vercel.
3. Keep the detected framework as Next.js.
4. Use npm run build as the build command if Vercel asks for one.
5. Deploy. No environment variables are needed for the current browser-only editor.

## Notes

The current release is intentionally local-only. It does not attempt to detect whether an image was generated by a particular provider. It adds the label the user chooses, which is the right first step for clear sharing.
